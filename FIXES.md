# The port's fixes

Each entry is a place where tpw-port deliberately behaves differently from the 1999 Mac build. tpw-decomp keeps the
Mac's behaviour, bugs included; the port builds the file under overrides/ in place of the submodule's file of the
same path. Everything else in the port is the platform layer (platform/, launcher/), which replaces the Mac's
system calls and is not a change to the game's behaviour. The rows of unit win are the Windows build's; most of them
only let a file compile with MinGW or link as COFF, and change nothing the game does on any system. The rows of unit
linux are the Linux build's: each lets a file compile with GCC, and changes nothing the game does on any system.
